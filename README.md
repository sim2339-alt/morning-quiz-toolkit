# ☀️ 초등 아침 활동 창의 퀴즈 생성기 (Morning Quiz Toolkit)

이 저장소는 초등학교 아침 활동 시간에 학생들과 함께 풀 수 있는 재미있는 퀴즈(초성 퀴즈, 넌센스, 두뇌 수학, 창의력 연상)를 자동으로 뽑아주는 도구입니다.

> 🤖 **제작**: 이신엽 선생님 & 피클 비서 몽실이  
> 🏫 **용도**: 초등 교실 아침 두뇌 스트레칭 및 수업 전 집중 활동

---

## 🚀 실행 방법

```bash
python3 quiz_generator.py
```

## 🧩 수록된 퀴즈 유형
1. **초성 퀴즈**: 교실 및 일상 사물 맞히기
2. **넌센스 퀴즈**: 웃음으로 시작하는 아침
3. **두뇌 스트레칭 수학**: 가벼운 연산 및 각도 문제
4. **창의력 연상 퀴즈**: 공통점 찾기 및 수수께끼
